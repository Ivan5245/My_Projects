Здесь собраны проекты, демонстрирующие мои навыки в машинном обучении, анализе данных и построении пайплайнов. Каждый проект оформлен как самостоятельная работа с четкой структурой, воспроизводимым кодом и выводами.
Важные папки: 
1)RAG-содержит проект по построению RAG на основе небольших ЛЛМ.
2)exploratory analysist-содержит проект по разведывательному анализу датасета.
3)Gold_cost_prediction-содержит проект по обучению LSTM прогнозированию цены на золото + инженерию признаков
